\# Projet mobile : TechPedia



\## 1. Présentation du projet



TechPedia est une application mobile qui permet de découvrir l'histoire de l'informatique et les personnes qui ont contribué à son évolution.



L'application permet aussi de tester ses connaissances grâce à un petit quiz interactif.



\## 2. Les pages de l'application



\### Page d'accueil

La page d'accueil présente l'application et permet d'accéder aux deux autres pages.



!\[Page d'accueil](images/01-accueil.png)



\*\*Figure 1 : Page d'accueil de TechPedia.\*\* Cette page présente l'application et permet d'accéder aux sections des pionniers et du quiz.



\### Page des pionniers

Cette page présente six personnalités importantes de l'histoire de l'informatique : Ada Lovelace, Alan Turing, Grace Hopper, Tim Berners-Lee, Dennis Ritchie et Linus Torvalds.



!\[Les pionniers](images/02-pionniers.png)



\*\*Figure 2 : Les pionniers de l'informatique.\*\* Cette page présente six personnalités importantes qui ont contribué à l'évolution de l'informatique.



\### Page du quiz

Cette page contient deux questions pour tester les connaissances de l'utilisateur. Un message s'affiche selon la réponse choisie.



!\[Quiz](images/03-quiz.png)



\*\*Figure 3 : Quiz TechPedia.\*\* Cette page permet de tester ses connaissances sur l'histoire de l'informatique et affiche un message selon la réponse choisie.
