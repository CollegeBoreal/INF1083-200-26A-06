## Objectif
Créer une application NativeScript Angular
permettant de rechercher un pays à partir
du nom de sa capitale.

## Technologies utilisées
- NativeScript
- Angular
- TypeScript
- RxJS
- HttpClient
- API REST

## Fonctionnement
1. L'utilisateur saisit une capitale.
2. Il appuie sur le bouton Search.
3. Le service Angular interroge une API.
4. RxJS traite la réponse.
5. Les pays sont affichés dans un ListView.
