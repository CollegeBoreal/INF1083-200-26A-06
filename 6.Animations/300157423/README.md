1. Introduction

Dans ce laboratoire, j'ai créé une application mobile avec NativeScript et Angular. Le but est d'apprendre à utiliser les animations sur un élément graphique.

2. Création du projet

J'ai utilisé Visual Studio Code pour créer et modifier mon application. Ensuite, j'ai lancé le projet sur un émulateur Android.

3. Modification des fichiers

J'ai travaillé sur deux fichiers :

browse.component.html : affichage du carré bleu, de la lettre N et du bouton Animate.

browse.component.ts : ajout des animations avec TypeScript.

4. Animations réalisées

J'ai utilisé les propriétés suivantes :

opacity : disparition et réapparition.

translate : déplacement de l'élément.

scale : agrandissement et réduction.

rotate : rotation de l'élément.
