**Nom :** 300157250  
**Cours :** INF1083  
**Technologie :** NativeScript avec Angular

## 1. Introduction

Ce travail consiste à réaliser différentes animations dans une application mobile développée avec NativeScript et Angular.

Deux types d'animations ont été réalisés : les animations déclaratives avec SCSS et les animations impératives avec TypeScript.

## 2. Animation déclarative – Home

Dans la page Home, un bouton change progressivement de couleur du rouge au vert en deux secondes.

**Technologies utilisées :**
- SCSS
- @keyframes
- animation-duration
- animation-fill-mode

## 3. Animation impérative – Browse

Dans la page Browse, un bouton nommé Animate permet de lancer plusieurs animations sur une image.

Les animations réalisées sont :
- Disparition et réapparition de l'image.
- Déplacement de l'image.
- Agrandissement et réduction.
- Rotation de 180 degrés et retour à la position initiale.

**Technologie utilisée :** TypeScript avec la méthode animate() de NativeScript.
