## Serveur de développement

Pour démarrer un serveur de développement local, exécutez :

```bash
ng serve
```

Une fois le serveur démarré, ouvrez votre navigateur et accédez à l'adresse `http://localhost:4200/`.

L'application se rechargera automatiquement chaque fois que vous modifierez un fichier source.

## Génération de code

Angular CLI comprend des outils permettant de générer automatiquement du code. Pour créer un nouveau composant, exécutez :

```bash
ng generate component component-name
```

Pour consulter la liste complète des éléments pouvant être générés (comme les composants, les directives ou les pipes), exécutez :

```bash
ng generate --help
```

## Compilation

Pour compiler le projet, exécutez :

```bash
ng build
```

Cette commande compile le projet et enregistre les fichiers générés dans le dossier `dist/`.

Par défaut, la compilation de production optimise l'application pour améliorer ses performances et sa rapidité.

## Exécution des tests unitaires

Pour exécuter les tests unitaires avec l'outil [Vitest](https://vitest.dev/), utilisez la commande suivante :

```bash
ng test
```

## Exécution des tests de bout en bout

Pour exécuter les tests de bout en bout (e2e), utilisez :

```bash
ng e2e
```

Angular CLI ne fournit pas de framework de tests de bout en bout par défaut. Vous pouvez choisir celui qui convient à vos besoins.
