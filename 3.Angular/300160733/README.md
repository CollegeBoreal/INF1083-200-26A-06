# Laboratoire Angular - INF1083

## Étudiant
Numéro : 300160733

## Objectif
Créer une application Web avec Angular.

## Travail réalisé
- Installation de Node.js et Angular CLI
- Création du projet Angular B300160733
- Création du composant Accueil
- Utilisation du Data Binding
- Création d'un bouton avec un événement
- Utilisation des directives ngIf et ngFor
- Affichage d'une liste d'utilisateurs
- Connexion à une API REST avec HttpClient
- Récupération des utilisateurs depuis une API
- Configuration du routage Angular
- Modification du style CSS

## Exécution du projet

npm install

ng serve

Adresse : http://localhost:4200

## Résultat
L'application affiche un message de bienvenue, une liste
d'utilisateurs et les données récupérées depuis une API REST.
