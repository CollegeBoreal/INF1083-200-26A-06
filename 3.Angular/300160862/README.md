## Description

Ce projet présente une application Angular contenant un composant d’accueil.

## Fonctionnalités réalisées

- Affichage du titre et du nom avec le Data Binding
- Bouton avec un événement `(click)`
- Affichage conditionnel avec `@if`
- Affichage d’une liste avec `@for`
- Consommation d’une API REST avec `HttpClient`
- Routage vers le composant d’accueil
- Application d’un style CSS au titre
