3. Travail réalisé
J’ai réalisé les éléments suivants :
- Création du projet Angular B300159887.
- Création du composant Accueil.
- Utilisation du data binding avec {{ titre }}.
- Création d’une liste d’étudiants.
- Ajout d’un étudiant avec un formulaire.
- Suppression d’un étudiant.
- Création d’un bouton avec un événement click.
- Ajout de styles CSS.
- Création d’un service Utilisateurs.
- Configuration de HttpClient.
- Connexion à une API REST avec JSONPlaceholder.
- Affichage des utilisateurs récupérés par l’API.
3. API REST
L’application utilise l’API :
https://jsonplaceholder.typicode.com/users
Les données récupérées sont affichées dans l'application avec le nom et le courriel des utilisateurs.
4. Résultat
L'application fonctionne avec :
- Bienvenue INF1083
- Liste des étudiants
- Ajout d'étudiants
- Suppression d'étudiants
- Bouton interactif
- Utilisateurs provenant de l'API REST
5. Conclusion
Ce laboratoire m'a permis de comprendre les bases d'Angular et de créer une application Web interactive. J'ai également appris comment connecter une application Angular à une API REST et afficher les données récupérées.
