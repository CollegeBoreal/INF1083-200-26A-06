1. Introduction

Dans ce laboratoire, j'ai réalisé une première application avec Angular. L'objectif était de découvrir la création d'un projet Angular, les composants, la liaison de données, les événements, les directives, l'utilisation d'une API REST, le routage et la mise en forme avec CSS.

2. Création du projet Angular

J'ai installé Angular CLI et créé le projet B300156534. Le projet utilise Angular CLI 22.2.2, Node.js 24.21.0, npm 11.19.0 et CSS avec le routage Angular.

Commandes utilisées :

npm install -g @angular/cli
ng new B300156534

3. Création du composant Accueil

J'ai créé le composant Accueil et ajouté un message de bienvenue « Bienvenue INF1083 ». Une liste d'étudiants contenant Alice, Bob et Charlie est également affichée.

4. Liaison de données et événements

L'application permet d'ajouter un étudiant avec un champ de texte et un bouton « Ajouter ». Elle permet aussi de supprimer un étudiant avec le bouton « Supprimer ». Un message confirme l'ajout d'un étudiant.

5. API REST

J'ai utilisé l'API REST JSONPlaceholder pour récupérer une liste d'utilisateurs. L'application utilise HttpClient et affiche le nom et le courriel des utilisateurs.

API utilisée : https://jsonplaceholder.typicode.com/users

6. Routage Angular

J'ai créé les composants Accueil, Utilisateurs, Configuration et Contact. La barre de navigation permet de passer d'une page à l'autre grâce au routage Angular.

7. Mise en forme CSS

J'ai ajouté du CSS afin d'améliorer l'apparence de l'application, notamment la barre de navigation, les liens, les champs de texte, les boutons et les titres.

8. Tests de l'application

Affichage de la page d'accueil.

Ajout d'un étudiant.

Suppression d'un étudiant.

Récupération des utilisateurs avec l'API REST.

Navigation entre les différentes pages.

Affichage de la mise en forme CSS.

9. Git et GitHub

Le projet a été intégré au dépôt GitHub du cours INF1083-200-26A-06, dans le dossier 3.Angular/300156534/B300156534. Les modifications ont été enregistrées avec Git et envoyées sur GitHub avec un commit et un push. Un pull --rebase a été utilisé avant le push afin d'intégrer les changements présents sur le dépôt distant.

10. Conclusion

Ce laboratoire m'a permis de découvrir les bases d'Angular et de créer une application fonctionnelle. J'ai appris à créer des composants, utiliser la liaison de données et les événements, gérer une liste, consommer une API REST, configurer le routage, utiliser CSS et gérer le projet avec Git et GitHub.
