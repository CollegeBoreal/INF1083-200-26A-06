## INF1083 – IDE, Git et GitHub
### But du travail

Le but de ce travail est de pratiquer l’utilisation de Git et GitHub, de découvrir l’utilisation de l’éditeur Nano et de comprendre comment gérer un projet local et le synchroniser avec un dépôt distant.

Ce travail permet également de pratiquer les commandes Git de base et de mieux comprendre le fonctionnement du dépôt local et du dépôt GitHub.

#### Travail réalisé

Dans ce travail, j’ai réalisé les étapes suivantes :


Pour commencer, j’ai créé un répertoire Developer afin d’organiser mon environnement de travail mais ce dossier existait deja. J’ai ensuite cloné le dépôt du cours INF1083 à partir de GitHub à l’aide de la commande git clone. Après avoir cloné le dépôt, je me suis déplacée dans le répertoire correspondant au travail et j’ai créé mon dossier personnel avec mon numéro d’étudiant.
