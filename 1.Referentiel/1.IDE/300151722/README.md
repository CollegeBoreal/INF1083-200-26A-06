## Description du travail – IDE et GitHub

**Nom et prénom :** Islam Oustani  
**Numéro d'étudiant :** 300151722  
**Cours :** INF1083 – Développement d'applications

### Description

Ce laboratoire présente les bases de l'utilisation de Git, GitHub et Visual Studio Code (VS Code).

Le travail consiste à cloner le dépôt GitHub du cours, à créer un répertoire personnel et à ajouter un fichier README.md pour documenter le projet.

Il permet également de découvrir les principales commandes Git, comme `git add`, `git status`, `git commit`, `git pull` et `git push`, afin de gérer les modifications et de les envoyer vers GitHub.

Une autre partie du laboratoire concerne la configuration d'une clé SSH pour établir une connexion sécurisée avec GitHub.

Enfin, Visual Studio Code est présenté comme environnement de développement pour consulter, modifier et organiser les fichiers du projet.

### Objectif

Comprendre le fonctionnement de Git et GitHub et apprendre à gérer un projet de développement à l'aide d'un environnement de développement intégré (IDE).
