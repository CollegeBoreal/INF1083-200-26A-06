Description du Travail : Atelier Git et Environnement de Développement (IDE)
Cet atelier a pour objectif principal d'initier l'étudiant à l'utilisation de l'outil de contrôle de version Git et à la gestion de projets de développement en ligne de commande.

Le travail se déroule à travers plusieurs grandes étapes pratiques :

Initialisation de l'environnement local :

Création d'un répertoire de développement dédié (Developer) et clonage du dépôt distant du cours fourni sur GitHub (INF1083-200-26A-06).

Création du répertoire personnel et du fichier de suivi :

Création d'un sous-dossier personnel portant l'identifiant Boréal de l'étudiant (🆔) dans le répertoire de l'atelier.

Ajout d'un fichier de documentation textuel (README.md) à l'intérieur de ce dossier personnel.

Suivi des modifications avec l'ajout des fichiers à la zone de staging (git add).

Configuration de l'identité et validation (Commit) :

Configuration globale de Git (éditeur de texte par défaut avec nano, nom d'utilisateur et adresse courriel).

Signature et validation du travail réalisé au moyen d'un commentaire initial (git commit).

Mise à jour du dépôt local via git pull.

Sécurisation et authentification SSH :

Génération et gestion d'une clé SSH (ssh-keygen) dédiée pour sécuriser les communications avec la plateforme GitHub.

Configuration du fichier client SSH (~/.ssh/config) et association de la clé publique au compte GitHub de l'utilisateur.

Publication finale sur le dépôt distant :

Modification de l'URL du dépôt distant pour utiliser le protocole SSH (git remote set-url).

Envoi et publication finale des modifications vers le serveur distant GitHub (git push).
