


# 🚀 Créer votre première application


- [ ] Créer un répertoire avec son 🆔 et ajouter le fichier README.md et un répertoire `images` 🖼️


- [ ] Dans votre répertoire 🆔, Créer un projet :

```bash
ns create B🆔
```

---

## 🚀 Aprés la création du projet: 

Éxécuter selon la plateforme

```lua
[@nativescript/webpack] Initialized config.
Project B🆔 was successfully created.

Now you can navigate to your project with cd B🆔 and then:

Run the project on multiple devices:

  $ ns run ios
  $ ns run android

Debug the project with Chrome DevTools:

  $ ns debug ios
  $ ns debug android

For more options consult the docs or run ns --help
```

Se déplacer dans le dossier :

```bash
cd 🆔
```
