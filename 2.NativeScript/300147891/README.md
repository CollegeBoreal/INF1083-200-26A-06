 TP NativeScript - Personnalités guinéennnes
## 1. Présentation du projet

Dans ce projet, j'ai créé ma première apllication mobile avec NativeScript en utilisant JavaScript.
Mon application s'appelle 'Personnalités guinéennes'.
Elle permet d'afficher une liste de cinq personnalités et de sélectionnerr une personnalité pour afficher un message.

## 2. Outils utilisés 
Visual Studio Code
NativeScript
JavaScript
Android Emulator
Powershell

## 3. Création du projet

J'ai créé mon projet NativeScript avec la commande suivante :

powershell

ns create B

## 4. Exécution de l'application

Pour entrer dans le dossier du projet :

powershell

cd B

Pour lancer l'application sur l'émulateur Android :

powershell

ns run android
