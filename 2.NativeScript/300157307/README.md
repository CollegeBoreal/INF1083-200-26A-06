TP 2 – NativeScript : Créer votre première application

Cours : INF1083 – Développement d'applications  
Étudiant : Amara Djida
 
1. Introduction

Dans ce laboratoire, l'objectif est de découvrir NativeScript et de créer une première application mobile. NativeScript est un environnement de développement qui permet de créer des applications mobiles en utilisant des technologies de développement web.

Ce travail permet de se familiariser avec la création d'un projet, le choix d'un framework, la configuration initiale et les différentes commandes nécessaires pour exécuter et déboguer une application.

2. Création du projet NativeScript

La première étape consiste à créer un nouveau projet avec NativeScript à partir du terminal.

Pour cela, j'ai utilisé la commande suivante :

```bash
ns create B300157307
```

Cette commande permet de démarrer l'assistant de création d'un nouveau projet NativeScript.

Pendant la création, plusieurs choix sont proposés afin de configurer l'application selon les besoins du développeur.

Options sélectionnées

Les options choisies pour ce laboratoire sont :

- Framework :Angular
-Template :Hello World

J'ai choisi Angular pour structurer l'application et faciliter son développement. Le modèle Hello World permet de commencer avec une application simple qui sert de base pour les prochaines modifications.

3. Création et initialisation du projet

Après avoir sélectionné les options, NativeScript procède à la création du projet et à l'installation de sa configuration initiale.

Une fois la création terminée, le message suivant confirme que le projet a été créé :

```text
Project B300157307 was successfully created.
```

Cette étape permet d'obtenir la structure de base nécessaire au développement de l'application.

4. Accéder au répertoire du projet

Après la création, il faut se déplacer dans le dossier du projet afin de pouvoir utiliser les commandes NativeScript.

La commande utilisée est :

```bash
cd B300157307
```

Cette commande permet d'accéder au répertoire contenant les fichiers de l'application.

Il est important d'être dans le bon dossier avant d'exécuter les commandes de lancement ou de débogage.

5. Exécution de l'application

NativeScript permet d'exécuter une application sur différentes plateformes, notamment Android et iOS.

Les commandes présentées dans le laboratoire sont les suivantes :

Exécution sur iOS :

```bash
ns run ios
```

Exécution sur Android :

```bash
ns run android
```

Ces commandes permettent de lancer l'application sur la plateforme correspondante. L'exécution nécessite toutefois un environnement de développement compatible et correctement configuré.

6. Débogage de l'application

Le débogage est une étape importante du développement. Il permet de vérifier le comportement de l'application, de repérer les erreurs et de faciliter leur correction.

NativeScript propose les commandes suivantes :

Débogage sur iOS :

```bash
ns debug ios
```

Débogage sur Android :

```bash
ns debug android
```

Ces commandes permettent de démarrer l'application en mode débogage sur la plateforme choisie.

7. Les principales commandes utilisées

| Commande | Description |
|---|---|
| `ns create B300157307` | Créer un nouveau projet |
| `cd B300157307` | Accéder au dossier du projet |
| `ns run ios` | Exécuter l'application sur iOS |
| `ns run android` | Exécuter l'application sur Android |
| `ns debug ios` | Déboguer sur iOS |
| `ns debug android` | Déboguer sur Android |

8. Conclusion

Ce laboratoire m'a permis de découvrir l'environnement NativeScript et de comprendre les principales étapes de création d'une application mobile.

J'ai appris à créer un projet, à sélectionner Angular comme framework et Hello World comme modèle de départ. J'ai également découvert les commandes permettant de naviguer dans le projet, de lancer une application et de démarrer une session de débogage.

Ces connaissances constituent une première étape dans l'apprentissage du développement d'applications mobiles et serviront de base pour les prochains laboratoires du cours INF1083.
