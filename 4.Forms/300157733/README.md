Objectif

L'objectif de ce laboratoire était de créer un formulaire Angular avec NativeScript afin de recueillir un courriel et un nom d'utilisateur, puis d'afficher ces données dans la console lors du clic sur un bouton.

Travail réalisé
Création du répertoire 300157733
Création du projet B300157733
Ajout d'un champ Email
Ajout d'un champ Username
Ajout du bouton Sign Up
Programmation de la méthode onButtonTap()
Affichage des données saisies dans la console au format JSON
Test du projet sur un émulateur Android
Sauvegarde et envoi du projet sur GitHub
