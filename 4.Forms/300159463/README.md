# Laboratoire 8 – Forms

**ID étudiant :** 300159463

## Objectif

Créer une application mobile avec NativeScript et Angular en utilisant ReactiveForms.

## Fonctionnalités

- Saisie d'une adresse courriel
- Saisie d'un nom d'utilisateur
- Bouton Sign up
- Affichage du courriel et du nom d'utilisateur dans la console

## Technologies utilisées

- NativeScript
- Angular
- TypeScript
- Android Studio
- Visual Studio Code

## Résultat

L'application affiche un formulaire contenant deux champs : Email et Username.

Lorsque l'utilisateur clique sur le bouton Sign up, les informations saisies sont affichées dans la console.
